# Umut Karademir — portfolio

[Visit the website ↗](https://umut-karademir-portfolio.snowy-crumb-3052.chatgpt.site)

A personal collection of research and projects across communication, human behaviour and digital experiences.

## Selected case studies

- **Master’s thesis:** a 98-participant mixed-method study of sustainability communication in AI shopping conversations.
- **RealLab:** interview research on collaboration between students, academics and companies, with project lead Peren Özturan.
- **Responsible product search:** research with Frans van der Sluis; a short paper submitted to CHIIR 2027 (not an accepted publication).

Read the expandable case summaries on the website for context, contribution, approach and limitations. This repository contains the portfolio website source; underlying research datasets, original thesis code and paper PDFs are not included.

## Preview locally

Serve the `dist/` directory with any static HTTP server. Open its local URL in a browser. No build or dependencies are required.

## Files

- `dist/index.html`: content and native expandable project summaries.
- `dist/style.css`: responsive layout, typography and visual system.
- `dist/icon.svg`: monogram favicon.

Built with HTML and CSS. No analytics, tracking scripts or external font dependencies.
